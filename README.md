Разработка и исследование «темпорального процессора»
для информационно- аналитических систем

Цель работы: Приобрести навыки представления и использования
темпоральных компонентов знаний в информационных и управляющих
системах.

Задачи: Научиться представлять темпоральные атрибуты знаний;
разрабатывать алгоритмы поиска темпоральных характеристик в
реляционных базах данных; разрабатывать интерфейсы пользователей
для имитационных моделей; разрабатывать алгоритмы анализа
темпоральных отношений для различных позиций наблюдения
(наблюдателя).
