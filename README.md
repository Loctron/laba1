# Лабораторная работа №1  
## Разработка и исследование «темпорального процессора» для информационно-аналитических систем

---

## **Цель работы**

Приобрести навыки представления и использования темпоральных компонентов знаний в информационных и управляющих системах.

---

## **Задачи работы**

В ходе выполнения лабораторной работы необходимо:

- освоить представление **темпоральных атрибутов знаний**;
- разработать алгоритмы поиска темпоральных характеристик в реляционных базах данных;
- реализовать пользовательский интерфейс для имитационной модели темпорального процессора;
- разработать алгоритмы анализа темпоральных отношений для различных позиций наблюдения (наблюдателя).
